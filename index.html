⚙️ ตั้งค่าการเชื่อมโยงข้อมูล Google Sheets (พร้อมระบบประเมิน)

วาง Web App URL ที่ได้จาก Google Apps Script เพื่อให้ระบบส่งการอัปเดตกลับไปยัง Google Sheets

ขั้นตอนการติดตั้ง Google Apps Script (อัปเดตใหม่):
  1. เปิดไฟล์ Google Sheets ➔ ไปที่เมนู ส่วนขยาย (Extensions) ➔ เลือก Apps Script
  2. นำโค้ดด้านล่างไปวางแทนที่โค้ดเดิมทั้งหมด
  3. กด ทำให้ใช้งานได้ (Deploy) ➔ เลือก การทำให้ใช้งานได้ใหม่ (New deployment)
  4. เลือกประเภทเป็น เว็บแอป (Web app) ➔ กำหนด ผู้มีสิทธิ์เข้าถึง (Who has access) เป็น ทุกคน (Anyone)
  5. คัดลอก Web App URL นำมาวางใส่ในช่องด้านบนแล้วกดบันทึก
